# F1 Strategy Simulator

Simulate a Formula 1 race strategy — circuit, driver, weather, tyres, and one pit stop —
and see the estimated result: finishing position, race time, a lap chart, and tyre wear.

## Status
🚧 Early development — building in public, step by step.

## Stack
Next.js · TypeScript · Tailwind CSS · AWS Lambda · API Gateway · DynamoDB · AWS CDK
